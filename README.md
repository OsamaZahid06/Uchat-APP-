UChat App

UChat is a real-time communication application designed to provide users with a simple and interactive platform for connecting and chatting with other users.

The application includes features such as user profiles, real-time messaging, online-user status, user search, typing indicators, and audio/video communication. It uses modern web technologies to provide a responsive and smooth chat experience.

Key Features
🔐 User authentication
👤 User profiles
💬 Real-time one-to-one messaging
🟢 Online/offline user status
🔎 Search users by profile name
⌨️ Typing indicators
📩 Real-time message delivery
📞 Audio calling
🎥 Video calling
📱 Responsive chat interface
🔌 Socket-based real-time communication
Technologies

Depending on your current implementation, your UChat project can be described as using:

Frontend: React.js
Backend: Node.js / Express.js
Real-time Communication: Socket.IO
Database: SQL/NoSQL database
Authentication: JWT
API: REST API
